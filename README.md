# VK Личный 0.3 — локальный интерактивный прототип

## Запуск
Откройте `index.html` в современном браузере. Для установки как PWA и работы Service Worker нужен HTTPS-хостинг или localhost. На iPhone: откройте HTTPS-адрес в Safari → «Поделиться» → «На экран Домой».

## Что есть в сборке
- Четыре нижние вкладки: Лента, Уведомления, Сообщения, Меню.
- Лента, демо-уведомления, профиль, меню, настройки, редактор записи/истории.
- В сообщениях первым экраном показывается список контактов, поиск, переключение «Все друзья» / «Недавние диалоги» и отдельный экран переписки.
- Меню действий контакта: звук, закрепление, непрочитанное, архив, скрытие, удаление, блокировка в макете, очистка локальной истории и жалоба-заглушка. Состояния звука/закрепления/непрочитанного/архива/блокировки и скрытия сохраняются локально в браузере.
- Отправка текста, выбор emoji и локальный выбор медиа работают только внутри демонстрационного интерфейса.
- Светлая/тёмная тема и PWA manifest/service worker.

## Важные ограничения
Это НЕ официальный клиент VK и пока НЕ подключён к аккаунту. Контакты, диалоги, уведомления и публикации демонстрационные. Отправка сообщения добавляет пузырь только на экран; публикация не уходит в VK; выбор файла не загружает его на сервер. Блокировка, архив, жалоба и другие действия не меняют настройки вашего аккаунта VK.

## Правила безопасности интеграции
- Не вводите пароль VK в этот прототип.
- Не вставляйте в него access token, cookie, session key или ключи официального приложения.
- Не используем перехват трафика, обход ограничений, подмену User-Agent/официального клиента или чужие токены.
- Любая будущая интеграция должна опираться на актуальную официальную документацию VK, разрешённый OAuth-сценарий и минимальные права. Секреты приложения нельзя хранить в браузерном JavaScript; если выбранный OAuth/API-сценарий требует секрет, он должен находиться только на защищённом сервере.
- До проверки актуальных правил и доступности конкретных методов никакой реальный OAuth/API-запрос не выполняется. Доступность API не гарантирует, что VK одобрит сторонний клиент или все нужные функции.

## Технические ограничения
Нет VK OAuth, VK API, реальных друзей/сообщений/публикаций, серверной синхронизации, реальных жалоб/блокировок, push-доставки и серверного хранения. Локальные состояния хранятся в `localStorage` этого браузера и не синхронизируются между устройствами.

Push при закрытом приложении требует HTTPS, поддержки браузера/ОС, разрешения пользователя, Service Worker, push-подписки и серверной отправки (VAPID/Web Push либо соответствующей инфраструктуры). Нажатие разрешения само по себе не означает, что push работает.

## Проверка
Перед публикацией проверьте работу на iPhone Safari и Windows-браузере. Не размещайте публично демо с персональными данными.
